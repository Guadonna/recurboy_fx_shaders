# Recursive Transformations 0.2.0

Добавлено пять эффектов; всего десять.

- **Corner Echoes** — Копии памяти стягиваются к углу кадра.
- **Opposing Tunnels** — Две половины изображения рекурсивно движутся в противоположных масштабах.
- **Strip Inception** — Каждая горизонтальная полоса содержит уменьшенную версию памяти.
- **Orbit Frames** — Рамка памяти вращается и смещается вокруг текущего кадра.
- **Foldback Memory** — Рекурсивная память выворачивается по V-образному сгибу.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
