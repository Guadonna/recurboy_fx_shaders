# Displacement Mapping 0.2.0

Добавлено пять эффектов; всего десять.

- **Edge Squeeze** — Соседние перепады яркости сжимают и растягивают горизонтальные участки.
- **Scan Twist** — Полосы разной высоты поворачивают локальное направление сдвига.
- **Cell Lenses** — Каждая клетка сетки работает как отдельная линза.
- **Temporal Relief** — Разность текущего и прошлого кадров задаёт смещение по диагонали.
- **Crossed Maps** — Две смещённые карты яркости управляют разными осями.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
