# v0.3.0 — рост от видео, перенос цвета и движущийся displacement

Переработаны два эффекта:

- **Differential growth:** фронты возникают от видео, переносят его цвет и деформируют выборку источника. Убраны центральный вихревой рисунок и окрашивание готовой маски текущим пикселем. Вернулся принцип возбуждения и восстановления из первой версии; это новая RGB-модель, не точная копия прежних двухкомпонентных уравнений.
- **Reaction diffusion:** равные соседние выборки по четырём сторонам и накопление возбуждения дают распространение от светлых объектов во всех направлениях. Добавлен displacement с медленно перемещающимся центром.

**Четвёртая ручка регулирует интенсивность displacement только после установки `docs/fx-fourth-knob.patch` и пересборки RecurBoy.** Штатный хост не передаёт её положение шейдеру. Без патча работает автоматическое движение с интенсивностью 30%; ручка регулирует скорость времени. С патчем: 0 выключает displacement, 1 даёт максимум, а центр движется независимо от ручки. Подробности — `docs/fourth-knob.md`.

ЧБ с чистым feedback остаётся ЧБ. Цвет теперь распространяется с фронтами, включая чёрные области; при смене цветного видео на ЧБ для немедленного удаления старого цвета сбросьте Wet в ноль на несколько кадров.

Проверены GLES-рендер, перенос цвета за пределы объекта, отсутствие самостоятельного рисунка на чёрном входе, направления распространения, перенос источника, диапазон четвёртой ручки и неподключённый хост. Патчи совместно применены к указанному upstream; передача контролов проверена компиляцией его C++ с тестовой заменой зависимостей openFrameworks. Это не сборка ARM и не аппаратный тест ручки.

В ZIP все 11 эффектов, инструкции и новые анимации. Девять остальных `.frag` совпадают с v0.2.0. Для обновления достаточно заменить два изменённых шейдера; для четвёртой ручки требуется отдельное изменение хоста.

**Предварительный релиз: 25 FPS и температура на Pi не измерены.** Бюджеты прежние: 6 чтений текстуры для reaction diffusion, 7 для differential growth, по одному проходу.
