# Datamosh 0.2.0

Добавлено пять эффектов; всего десять.

- **Cross Block Shear** — Макроблоки памяти сдвигаются попеременно по двум осям.
- **Column Melt** — Участки старого кадра стекают по столбцам с разной скоростью.
- **Motion Eraser** — Изменившиеся области стираются, раскрывая смещённый старый кадр.
- **Temporal Checker** — Шахматные блоки удерживают разные моменты времени.
- **Chroma Avalanche** — Цветность старого кадра растекается под текущей яркостью.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
