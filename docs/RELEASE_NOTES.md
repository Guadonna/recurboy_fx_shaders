# Phase Distortion 0.2.0

Добавлено пять эффектов; всего десять.

- **Triangle Phase Fold** — Треугольный носитель перегибает фазу горизонтального смещения.
- **Checker Phase** — Соседние клетки получают разные фазы одной волны.
- **Memory Phase** — Яркость прошлого кадра меняет фазу волн памяти.
- **Saw Phase Carrier** — Яркость сдвигает фазу пилообразных световых полос.
- **Opposed Phase Windows** — Две половины кадра используют противоположную фазу смещения.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
