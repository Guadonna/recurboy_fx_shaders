# Signal Interference 0.2.0

Добавлено пять эффектов; всего десять.

- **Mains Hum** — Широкие бегущие полосы яркости имитируют сетевой фон.
- **Tracking Bar** — Плавающая полоса нарушения трекинга сдвигает и зашумляет видео.
- **Multipath Comb** — Два отражённых сигнала образуют гребенчатые края.
- **Line Phase Noise** — Фаза каждой группы строк меняется независимо.
- **Burst Hold** — Короткие выпадения сигнала удерживают прошлое изображение в полосах.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
