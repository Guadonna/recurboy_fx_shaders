# Datamosh v0.1.0 — пять новых FX

Отдельная подборка в ветке `collections/datamosh`:

1. **Block Vectors** — смещение макроблоков и ошибочные векторы.
2. **Chroma Bleed** — отставание цвета относительно яркости.
3. **Motion Drag** — вязкое вытягивание старого кадра движением.
4. **Slice Loss** — пропадающие полосы и сдвиги строк.
5. **Keyframe Starvation** — плитки, застрявшие в разных моментах прошлого.

Все используют штатный интерфейс RecurBoy; патч передачи четвёртой ручки не требуется. Ручки: 0 — Wet/сброс, 1/2 — характер и глубина повреждений, 3 — скорость/направление временной модуляции. Старт: **100% / 55% / 90% / 65%**. Перед запуском ненадолго опустите Wet в ноль.

Один проход, 2–6 чтений текстуры, GLES 2.0 / GLSL ES 1.00. Это визуальные datamosh-эффекты через feedback, без изменения кодека или видеопотока. Chroma Bleed предназначен для цветного видео.

В ZIP ровно пять `.frag` в папке `Fx/`, руководство, анимация и контрольные суммы. Скопируйте их в `~/Fx/` либо `Fx` в корне USB. Префиксы `dm01…dm05` позволяют установить подборку рядом с Feedback FX.

Проверены реальные GLES compile/link/render, движение и смены сцены, память, ручки, ЧБ, сброс и точное удержание плиток. Архив воспроизводим. **25 FPS и температура на самой Pi не измерены**; релиз предварительный. Для надёжной обратной связи необходим корректный предыдущий framebuffer; приложена известная поправка к буферам upstream, сборка ARM не проверена.
