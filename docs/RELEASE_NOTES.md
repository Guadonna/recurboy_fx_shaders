# Databending 0.2.0

Добавлено пять эффектов; всего десять.

- **Scan Buffer Slip** — Куски строк читаются со сдвигом по вертикали.
- **Nibble Banks** — Чередующиеся банки значений по-разному переполняют цветовые каналы.
- **Word Swaps** — Повреждённые слова меняют порядок RGB-каналов в блоках.
- **Checksum Holes** — Повреждённые пакеты выпадают в чёрный или сохраняют старые данные.
- **Page Scroll** — Разные страницы цифрового изображения прокручиваются независимо.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
