# RecurBoy Patterns 0.2.1

Библиотека паттернов теперь находится в одной ветке [patterns](https://github.com/Guadonna/recurboy_fx_shaders/tree/patterns). [Главная страница](https://github.com/Guadonna/recurboy_fx_shaders/tree/main) содержит краткий путеводитель, [ветка fx](https://github.com/Guadonna/recurboy_fx_shaders/tree/fx) — обработку видео.

46 шейдеров в пяти категориях: Data Corrupt — 10, Digital — 10, Analog — 10, Organic — 10, Hybrid — 6. Шейдеры побайтово совпадают с Patterns 0.2.0; изменены организация, документация и автоматизация выпуска.

Вложения: пять ZIP категорий с инструкциями, `recurboy-all-patterns-v0.2.1.zip` и `SHA256SUMS`. В общем ZIP только `категория/*.frag`, без вложенной Shaders/ и служебных файлов. Скопируйте папки категорий в `/Shaders/` на флешке, выбор — через PATTERN. В отдельных ZIP уже есть `Shaders/<категория>/`.

Работа на штатном хосте, без патчей и пересборки. 2 898 GLES-сценариев и проверки упаковки пройдены. FPS и температура на Raspberry Pi ещё не измерены; выпуск сохраняет предварительный статус. Предыдущие версии остаются доступными.
