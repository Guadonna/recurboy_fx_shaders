**5 коллекций, 46 PATTERN-генераторов для штатного RecurBoy. Без патчей и пересборки прошивки.**

- Data Corrupt / Signal Decay — 10: блоки, битовые витражи, пакеты, адресные разрывы и кодовые ленты.
- Digital / Computational — 10: dithering, XOR/AND, Rule 90, вложенные рамки, булева геометрия и муар.
- Analog Echo / Electronic Memory — 10: эхо-контуры, протяжка, разъезд цветов, развёртка и биения.
- Organic Nature / Emergent Systems — 10: клеточные мембраны, лабиринты, грибные сети, мрамор и складки.
- Hybrid / Experimental — 6: органическая порча, жидкие блоки, паразит развёртки и другие сочетания.

По одному паттерну на каждую идею списка. Названия с фидбеком, ростом и диффузией обозначают лёгкие процедурные интерпретации: кадровой памяти, физического решателя и настоящего datamosh здесь нет. Старый CV Matrix с патчами и его релиз удалены по запросу; существующая ветка `patterns/cv-matrix` сохранена для новых коллекций.

Каждый файл рисует за один проход: 0 чтений текстур, 0 циклов, максимум 3 sin/cos. Без свечения и систем частиц. Ручки/CV 1–3 управляют рисунком; ручка 3 в нуле даёт ч/б. Ручка/CV 4 управляет штатной скоростью/направлением времени.

В релизе **пять отдельных ZIP**, **recurboy-all-patterns-v0.2.0.zip** и внешний **SHA256SUMS**. Общий ZIP содержит только `подборка/*.frag` без вложенной `Shaders/` и документации. Его папки нужно положить в `/Shaders` на флешке. В отдельных ZIP уже есть папка `Shaders/<подборка>/` и инструкция. Выбор — в меню PATTERN.

Проверены 46 файлов и 2 898 сценариев на Mesa EGL в 320×240, 720×576 и 720×480; тесты управления, ч/б, остановки и упаковки пройдены. **FPS ≥25 и температура на Raspberry Pi ещё не проверены** — выпуск предварительный до испытаний на устройстве. FX-коллекции остаются в отдельном релизе [Collections 1.2.0](https://github.com/Guadonna/recurboy_fx_shaders/releases/tag/collections-v1.2.0).
