# RecurBoy FX 1.3.0

Все FX теперь находятся в одной ветке [fx](https://github.com/Guadonna/recurboy_fx_shaders/tree/fx): **13 категорий, 131 шейдер**. [Главная страница](https://github.com/Guadonna/recurboy_fx_shaders/tree/main) — краткий путеводитель; [ветка patterns](https://github.com/Guadonna/recurboy_fx_shaders/tree/patterns) — самостоятельные PATTERN-генераторы.

Шейдеры побайтово сохранены из последних отдельных веток и выпуска Collections 1.2.0. Изменены организация, навигация и сборка релизов. Истории всех FX-категорий включены в ветку fx; старые версии релизов остаются доступными.

Вложения: **13 ZIP категорий**, **recurboy-all-fx-v1.3.0.zip**, внешний **SHA256SUMS**. В общем архиве только `категория/*.frag`, без вложенной Fx/, README или служебных файлов. Скопируйте папки категорий в `/Fx/` на флешке. Отдельные ZIP содержат Fx/ и подробные инструкции.

Категории: FB Growth — 11; Classic Feedback, Datamosh, Pixel Sorting, Displacement, Kaleidoscope, Recursive, Databending, Bitwise, Compression, Wave, Phase, Interference — по 10.

Проверены перенос файлов, сборка всех архивов, их содержимое и прежние проверки категорий из нового расположения. Алгоритмы эффектов не менялись. FPS и температура на Raspberry Pi ещё не измерены; аппаратные ограничения и требования к кадровой памяти описаны в инструкциях категорий. Выпуск сохраняет предварительный статус.
