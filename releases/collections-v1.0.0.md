# RecurBoy FX Collections 1.0.0

Один общий выпуск актуальных подборок — 16 FX:

- **Feedback 0.4.0:** 11 эффектов. Reaction diffusion без displacement, с регулировкой размера частиц второй физической ручкой; Differential growth сохраняет перенос цвета видео.
- **Datamosh 0.1.0:** Block Vectors, Chroma Bleed, Motion Drag, Slice Loss и Keyframe Starvation.

Скачайте нужный `recurboy-…zip` из Assets и скопируйте `.frag` из его папки `Fx/` в RecurBoy. Можно установить обе подборки. Каждый ZIP содержит своё руководство и внутренние контрольные суммы; Дополнительный `recurboy-all-collections-v1.0.0.zip` содержит все 16 эффектов в общей папке `Fx/` и инструкции каждой подборки. Общий `SHA256SUMS` проверяет все три архива. Автоматические Source code архивы относятся к каталогу main; для установки используйте ZIP подборок.

Шейдеры не изменены по сравнению с последними отдельными выпусками. Обновлены ссылки и схема публикации. Этот общий выпуск заменяет прежние отдельные релизы Organic/Feedback/Datamosh.

Предварительный выпуск: проверки GLES/Mesa и упаковки выполнены; FPS и температура на Raspberry Pi ещё не измерены.
