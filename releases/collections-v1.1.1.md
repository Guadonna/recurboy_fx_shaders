# RecurBoy FX Collections 1.1.1 — архив для устройства

Общий ZIP теперь содержит только шейдеры, разложенные по типам:

```text
feedback/
  01_liquid_memory.frag
  ...
datamosh/
  dm01_block_vectors.frag
  ...
displacement/
  dsp01_luma_relief.frag
  ...
```

В каждой из 12 папок непосредственно лежат `.frag`. Вложенные `Fx/`, инструкции, картинки, manifest и служебные файлы из общего ZIP удалены. Всего 66 шейдеров; их содержимое не изменено.

В релизе по-прежнему доступны 12 отдельных ZIP с документацией, общий `recurboy-all-collections-v1.1.1.zip` и внешний `SHA256SUMS`. Внешняя контрольная сумма проверяет весь общий ZIP, не добавляя служебные файлы в папки эффектов. Ссылки на инструкции и ветки — в главном README репозитория.

Проверены точные пути `тип/имя.frag`, отсутствие любых лишних файлов, количество шейдеров и побайтовое совпадение с отдельными подборками. Ревизии исходников и ранее успешные GLES-проверки сохранены из 1.1.0; упаковка не меняет работу шейдеров. FPS и температура на Raspberry Pi пока не измерены.
