# Pixel Sorting 0.2.0

Добавлено пять эффектов; всего десять.

- **Descending Rows** — Яркость убывает вдоль горизонтальных полос.
- **Serpentine Rows** — Направление рангов чередуется в соседних полосах.
- **Green Column Ranks** — Вертикальная сортировка по разнице зелёного и красного.
- **Tile Ranks** — Клетки переставляют три яркостных ранга внутри локальных рядов.
- **Bright Ridges** — Самый светлый ранг образует центральные гребни полос.

Прежние пять шейдеров заменены лёгкой локальной сортировкой трёх выборок. 4 чтения вместо 6, 3 сравнения вместо 10, ключи вычисляются один раз, без trig/pow/inout-сети. Имена файлов сохранены для прямой замены. Все десять вариантов прошли PAL-стресс 720×576, 256 кадров каждый, на Mesa. Это не подтверждает FPS или устранение зависания на Raspberry Pi.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
