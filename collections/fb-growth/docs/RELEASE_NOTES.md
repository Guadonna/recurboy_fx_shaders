# FB Growth 0.4.1

Прежняя подборка Feedback / Organic FX переименована в **FB Growth**, каталог `collections/fb-growth` ветки `fx`, каталог общего архива `fb-growth/`.

Все 11 шейдеров побайтово сохранены из версии 0.4.0; изменение касается названия, документации и упаковки. Каталог `collections/feedback` ветки `fx` содержит 10 новых классических feedback-эффектов.

При обновлении переименуйте прежнюю папку `feedback` на устройстве в `fb-growth`, затем скопируйте новую `feedback`. Имена `.frag` прежней подборки не изменились.

Релиз Collections 1.2.0 сохраняет общий архив формата `тип/*.frag`, без вложенных Fx/ и документации.
