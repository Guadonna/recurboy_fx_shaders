# Classic Feedback 0.1.0

Новая подборка из десяти классических feedback-эффектов.

- **Zoom In** — Предыдущий кадр плавно увеличивается, оставляя расширяющиеся следы.
- **Zoom Out** — Предыдущий кадр сжимается к центру, образуя вложенные контуры.
- **Rotation Echo** — Небольшой поворот каждого прошлого кадра создаёт спиральную память.
- **Horizontal Trails** — Память уходит влево или вправо, оставляя горизонтальные шлейфы.
- **Vertical Trails** — Память уходит вверх или вниз, оставляя вертикальные шлейфы.
- **Mirror Echo** — Зеркальное отражение предыдущего кадра накапливает симметричные двойники.
- **Luma Key Echo** — Яркие участки обновляют память, тёмные сохраняют старый кадр.
- **Difference Echo** — Разность с прошлым кадром порождает пульсирующие контуры движения.
- **RGB Echo** — Три цветовых канала прошлого кадра оставляют разнесённые эхо.
- **Frame Echo** — Рамка кадра удерживает вложенные копии, оставляя центр читаемым.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
