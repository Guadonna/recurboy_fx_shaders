# DATA CORRUPT / SIGNAL DECAY

[Все паттерны](https://github.com/Guadonna/recurboy_fx_shaders/tree/patterns) · [FX](https://github.com/Guadonna/recurboy_fx_shaders/tree/fx) · [Главная](https://github.com/Guadonna/recurboy_fx_shaders/tree/main)

10 самостоятельных PATTERN-шейдеров для штатного RecurBoy. Установка: скопировать папку `Shaders` из отдельного ZIP в корень USB; выбрать файл в меню PATTERN. В общем архиве папки подборок содержат только `.frag`; скопировать их целиком в `/Shaders/`.

Ручки 1–3 / CV 1–3 непрерывно меняют параметры. Ручка 4 / CV 4 управляет штатными скоростью и направлением времени; около середины — остановка. При ручке 3 в нуле изображение чёрно-белое; выше добавляется цвет одновременно с указанным параметром.

| Файл | Рисунок и механизм | Ручка 1 | Ручка 2 | Ручка 3 |
|---|---|---|---|---|
| `dc01_vector_blocks.frag` | **Vector Blocks** — Плитки смещают фазы движущихся полос; процедурная интерпретация переноса блоков без векторов видео. | Размер блоков | Разброс смещения | Заполнение / цвет |
| `dc02_bit_rot.frag` | **Bit Rot Raster** — Битовые флаги процедурного растра переключаются по адресам ячеек; нет чтения или порчи памяти. | Плотность растра | Доля повреждений | Битовая маска / цвет |
| `dc03_address_maze.frag` | **Address Maze** — Линейный адрес сетки переносится в другую строку и формирует сломанные штрихкоды. | Ширина адресного поля | Перестановка строк | Длина штрихов / цвет |
| `dc04_packet_islands.frag` | **Packet Islands** — Крупные кодовые плитки выпадают и возвращаются пачками; чистый генератор без видеовхода. | Число пакетов | Вероятность выпадения | Форма пакета / цвет |

| `dc07_rank_bands.frag` | **Rank Bands** — Упорядоченные ступени яркости строятся формулой внутри длинных полос; сортировки пикселей и циклов нет. | Число полос | Длина отсортированных пробегов | Число ступеней / цвет |

| `dc09_bitplane_cathedral.frag` | **Bitplane Cathedral** — Симметричные цифровые витражи из четырёх арифметически выделенных битовых плоскостей. | Масштаб витража | Перестановка битовых адресов | Выделение плоскостей / цвет |
| `dc10_smear_ribbons.frag` | **Smear Ribbons** — Кодовые отрезки вытягиваются в длинные ленты с жёсткими цифровыми окончаниями. | Число лент | Длина растяжения | Толщина / цвет |

Один проход, 0 чтений текстур, без циклов, свечения, частиц и дополнительных буферов. Названия с эхо, ростом и повреждением обозначают визуальные интерпретации: генераторы не обрабатывают входное видео и не сохраняют прошлые кадры. Служебное время циклически ограничено 1024 единицами; на границе возможна смена фазы. FPS и температура на Raspberry Pi ещё не измерены.
