# Kaleidoscope 0.2.0

Добавлено пять эффектов; всего десять.

- **Quadrant Spinner** — Четыре зеркальных квадранта поворачиваются вокруг центра.
- **Triangular Grid** — Ряды отражённых треугольников складывают изображение в мозаику.
- **Wandering Eye** — Центр радиальных отражений перемещается по изображению.
- **Mirror Memory** — Старое изображение проходит через вращающиеся зеркальные сектора.
- **Diamond Chambers** — Ромбические зеркальные ячейки раскрывают разные участки видео.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
