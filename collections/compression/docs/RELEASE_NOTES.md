# Compression Artifacts 0.2.0

Добавлено пять эффектов; всего десять.

- **DC Band Loss** — Полосы теряют среднюю яркость и делятся на грубые уровни.
- **Checker Residual** — Чётные блоки обновляют разность кадра, нечётные удерживают старые данные.
- **Edge Steps** — Ступени квантования усиливаются около контуров.
- **Staggered Blocks** — Строки макроблоков декодируются с разным смещением.
- **Chroma Dropout** — В отдельных блоках пропадает цветность, сохраняя яркость.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
