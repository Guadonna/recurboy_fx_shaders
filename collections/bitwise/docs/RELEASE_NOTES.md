# Bitwise Processing 0.2.0

Добавлено пять эффектов; всего десять.

- **XOR Threshold** — Разряды инвертируются там, где яркость пересекает движущийся порог.
- **AND Neighbours** — AND с соседней областью вырезает несовпадающие биты.
- **OR Stripes** — Полосы добавляют выбранные световые разряды без истории кадров.
- **Reverse Bits** — Порядок четырёх разрядов разворачивается внутри каждого канала.
- **Bitplane Weave** — Разные полосы показывают разные битовые плоскости изображения.

Один проход, новые эффекты используют 1–4 чтения текстур. Штатные ручки 0–3, без патча их передачи. Проверены реальные GLES-рендеры, параметры, история и цвет. FPS и температура на Pi пока не измерены.

В общем релизе Collections 1.2.0 архив All Collections содержит только `тип/*.frag`, без вложенной Fx/ и документации.
