# RecurBoy Kaleidoscope — 5 FX

[Все подборки](https://github.com/Guadonna/recurboy_fx_shaders/tree/main) · Ветка `collections/kaleidoscope` · Версия 0.1.0

Радиальные зеркала, плиточные отражения и спиральные симметрии.



## Установка и управление

Скопируйте `.frag` из `Fx/` этой подборки в `~/Fx/` на Pi или `Fx` в корне USB. Префикс `kal` отличает эти файлы от остальных подборок. В общем ZIP каждый тип находится в отдельной папке `kaleidoscope/` со своей `Fx/`.

Откройте FX, выберите шейдер, включите обработку. Ручки регулируются на странице EFFECT. Старт: **0/1/2/3 = 100% / 55% / 75% / 65%**. Ручка 0 — Wet; ноль выводит исходное видео и сбрасывает память. После переключения эффекта или цветного видео на ЧБ подержите Wet=0 несколько кадров.

Вторая и третья физические ручки — параметры A и B из таблицы. Четвёртая использует штатные часы: около середины модуляция останавливается, по краям ускоряется в противоположных направлениях. Видео и feedback продолжают обновляться. Патч передачи четвёртой ручки не требуется.

| Файл | Работа эффекта | A (ручка 1) | B (ручка 2) | Чтений |
|---|---|---|---|---:|
| `kal01_radial_glass.frag` | Классический вращающийся калейдоскоп. | Число секторов 3–24 | Масштаб | 2 |
| `kal02_mirror_tiles.frag` | Сетка вращающихся зеркальных комнат. | Число плиток | Угол отражения | 2 |
| `kal03_spiral_petals.frag` | Сектора закручиваются сильнее по мере удаления от центра. | Число лепестков | Закрутка | 2 |
| `kal04_twin_mandalas.frag` | Два смещённых центра симметрии перекрываются мягкой границей. | Расстояние между центрами | Число отражений | 3 |
| `kal05_prism_rings.frag` | Зеркальные сектора повторяются концентрическими кольцами. | Плотность колец | Количество граней | 2 |

Цвет берётся из видео. Эффекты разделения каналов и цветовой интерференции намеренно могут окрашивать ЧБ; остальные проверяются на сохранение ЧБ при чистой памяти. Битовые и overflow-эффекты намеренно меняют значения цвета.

## Совместимость и производительность

GLSL ES 1.00 / GLES 2.0; один проход, не более 6 выборок текстуры на пиксель, без циклов, float-буферов и изменений прошивки для управления. Эффекты с памятью используют только один предыдущий RGB8-кадр. Частоты и нагрузка не управляются шейдером. **25 FPS и температура на Raspberry Pi не измерены**; начинайте с SD и штатных 30 FPS. [Проверка на устройстве](docs/performance.md).

Feedback требует завершённого предыдущего кадра в отдельном framebuffer. В исследованном upstream RecurBoy/ofxVideoArtTools чтение и запись могут обращаться к одному буферу, что не определено в GLES. Приложен прежний `docs/feedback-pingpong.patch` к addon `00dc93725073b1cf5bfc5d4a56e8d3256a995d81`; это отдельная поправка хоста, не обязательное расширение ручек. На ARM она здесь не собрана. Если прошивка уже чередует буферы, патч не нужен. Лицензия addon включена рядом с патчем.

## Проверки

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
EGL_PLATFORM=surfaceless .venv/bin/python tools/validate_collection.py
.venv/bin/python tools/package.py
```

Компиляция и реальный GLES-рендер, сухой сигнал, история для feedback-эффектов, крайние ручки, изменение A/B и часов, ЧБ там, где оно предусмотрено, разные размеры кадра. Это программный Mesa, не аппаратная квалификация Pi.
