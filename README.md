# RecurBoy Phase Distortion — 10 FX

[Каталог](https://github.com/Guadonna/recurboy_fx_shaders/tree/main) · `collections/phase` · v0.2.0

Нелинейное изменение фазы носителя, радиальных волн и фаз цветовых каналов.



## Установка и ручки

В отдельном ZIP шейдеры находятся в `Fx/`; в All Collections — непосредственно в `phase/`, только `.frag`. Документация есть в отдельных ZIP и ветках. Обновление: замените одноимённые файлы. Префиксы шейдеров уникальны для типа эффектов.

На странице EFFECT: ручка 0 — Wet/сброс, 1 и 2 — из таблицы, 3 — штатная скорость и направление часов. Около середины четвёртой ручки модуляция останавливается, видео и память продолжают обновляться. Патч передачи ручки не нужен. Старт: **100% / 55% / 75% / 65%** (у первых пяти Datamosh можно поднять третью ручку до 90%). После смены эффекта подержите Wet=0 несколько кадров.

| Файл | Механизм | Ручка 1 | Ручка 2 | Чтений |
|---|---|---|---|---:|
| `phs01_sine_phase_warp.frag` | Вторая синусоида деформирует фазу основной волны смещения. | Частота носителя | Фазовый индекс | 2 |
| `phs02_phase_pinch.frag` | Нелинейная скорость фазы сжимает и растягивает каждую вертикальную полосу. | Число периодов | Перегиб фазы | 2 |
| `phs03_radial_phase_twist.frag` | Радиальные колебания модулируют угол изображения. | Частота колец | Глубина поворота | 2 |
| `phs04_video_phase_carrier.frag` | Яркость самого видео сдвигает фазу полосатого носителя. | Частота полос | Влияние видео на фазу | 1 |
| `phs05_rgb_phase_split.frag` | Разные фазы цветовых каналов формируют волнистое цветовое расслоение. | Частота носителя | Разница фаз | 4 |
| `phs06_triangle_phase_fold.frag` | Треугольный носитель перегибает фазу горизонтального смещения. | Частота | Индекс фазовой модуляции | 2 |
| `phs07_checker_phase.frag` | Соседние клетки получают разные фазы одной волны. | Размер клеток | Разница фаз | 2 |
| `phs08_memory_phase.frag` | Яркость прошлого кадра меняет фазу волн памяти. | Частота носителя | Глубина памяти | 3 |
| `phs09_saw_phase_carrier.frag` | Яркость сдвигает фазу пилообразных световых полос. | Частота | Влияние видео | 1 |
| `phs10_opposed_phase_windows.frag` | Две половины кадра используют противоположную фазу смещения. | Частота | Разница фаз | 2 |

Цвет берётся из источника. RGB-разделение и цветовая интерференция намеренно могут окрашивать ЧБ; остальные варианты проверяются на сохранение ЧБ с чистой памятью. Feedback сохраняет прежние цвета до сброса Wet.

## Производительность и проверки

GLES 2.0 / GLSL ES 1.00, один проход. Новые эффекты используют не более 4 чтений текстур; прежние — до 6. Pixel Sorting целиком ограничен 4 чтениями. **FPS и температура на Raspberry Pi не измерены**, облачные проверки не подтверждают устранение аппаратного зависания. [Проверка на устройстве](docs/performance.md).

Шейдеры с памятью требуют завершённого предыдущего RGB8 framebuffer. Исследованный upstream может читать и писать один буфер, что не определено GLES; отдельный прежний `docs/feedback-pingpong.patch` исправляет это для addon `00dc93725073b1cf5bfc5d4a56e8d3256a995d81`. Если хост уже чередует буферы, патч не нужен. На ARM он здесь не собран. Лицензия addon включена рядом. Pixel Sorting использует только текущее видео.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
EGL_PLATFORM=surfaceless .venv/bin/python tools/validate_collection.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python tools/package.py
```
