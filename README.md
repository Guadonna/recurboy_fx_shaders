# RecurBoy Shaders

Библиотека шейдеров для [RecurBoy](https://github.com/cyberboy666/recurBOY): обработка видео, обратная связь, цифровые искажения и самостоятельные генеративные паттерны.

## Две библиотеки

| Раздел | Что внутри | Скачать |
|---|---|---|
| **[FX →](https://github.com/Guadonna/recurboy_fx_shaders/tree/fx)** | 131 эффект в 13 категориях для обработки видео через меню EFFECT. | [Релиз FX 1.3.0](https://github.com/Guadonna/recurboy_fx_shaders/releases/tag/fx-v1.3.0) |
| **[Паттерны →](https://github.com/Guadonna/recurboy_fx_shaders/tree/patterns)** | 46 самостоятельных генераторов в 5 категориях для меню PATTERN. | [Релиз Patterns 0.2.1](https://github.com/Guadonna/recurboy_fx_shaders/releases/tag/patterns-v0.2.1) |

Откройте нужную ветку: там находятся подробный каталог, назначения ручек/CV, примеры и инструкции по установке. В `main` хранится только этот путеводитель.

## Как устроены архивы

В каждом выпуске есть **отдельный ZIP каждой категории**, **общий ZIP всей библиотеки** и контрольные суммы SHA-256. В общем архиве категории остаются в отдельных папках; внутри — только `.frag`, без вложенных служебных папок.

Папки из общего FX-архива копируются в `/Fx/` на флешке, из архива паттернов — в `/Shaders/`. Подробности совместимости и проверок производительности приведены в ветках библиотек.
